All Weather Slate

Six ideas, one rule

Each arm is one idea, built on its own branch and scored against main on the same 391 forecast dates from 1994-03, the first date the model is honest about. The statistic is the paired difference in mean Brier skill score, arm minus main, with a moving-block bootstrap over forecast dates (10,000 resamples, seed 20260908). The rule was committed before any arm ran: promising if the one-year 90% interval is above zero; confirmed in sample if the one-year 98.33% interval is (1 − 0.10/6, a Bonferroni correction for six arms); harmful if any horizon's 90% interval is below −0.02; void if the look-ahead audit fails or the independent review finds a leak.

What each arm found

Is A4 just a lucky seed?

A4 fits sixteen joint states by expectation maximisation from random starting points, so one lucky local optimum could produce a result this size. Before either variant ran, diagnostic 0004 fixed how to read two more seeds, the next two integers after the registered one: robust to initialisation if both keep the one-year 90% interval above zero, and seed-dependent if either does not. The diagnostic cannot change A4's registered verdict. It decides how strongly the result can be stated, and whether A4 can be recommended.

Combining the survivors: experiment 0003

The combination rule was also written before any arm reported. Stackable layers (A1's prior, A5's rates, A6's blend) change different stages and all compose; structures (A2, A3, A4) each replace the state space, so at most one is used, the one with the highest one-year difference. Eligible means promising or better, not harmful, not void, and a look-ahead review of exactly clean. Nothing is re-tuned.

Five and ten years

Secondary endpoints. The bootstrap blocks are as long as the horizon, so the five-year comparison rests on about 5.5 independent observations and the ten-year one on about 2.2. The dots move a lot; the intervals say how little that means.
